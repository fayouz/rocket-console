---
title: API du domaine
description: Routes de Rocket Console.
---

JSON, montants en centimes HT. Opérateur = `ROLE_ADMIN`. Application = jeton `rco_…` agissant pour elle-même.

| Méthode et chemin | Accès | Rôle |
|---|---|---|
| `GET /api/catalogue` | connecté, application | briques, options, offres, règles |
| `POST /api/catalogue/{bricks,options,plans}` · `PATCH …/{code}` · `DELETE …/{code}` | opérateur | éditer le catalogue (409 si utilisé) |
| `PUT /api/catalogue/pricing` | opérateur | `minimumMonthlyCents`, `volumeTiers` [{min, percent}], `yearlyFreeMonths`, `trialDays` |
| `GET /api/accounts?status=&q=` · `POST /api/accounts` | opérateur | liste (avec abonnement et montant mensuel), création |
| `GET/PATCH/DELETE /api/accounts/{slug}` | opérateur | fiche (membres, abonnements, devis, droits) |
| `POST /api/accounts/{slug}/members` · `PATCH/DELETE …/members/{id}` | opérateur | membres |
| `POST /api/accounts/{slug}/subscriptions` · `PATCH/DELETE /api/subscriptions/{id}` | opérateur | abonnement (422 : règles du catalogue) |
| `POST /api/quote` | opérateur | devis d'un brouillon (même corps qu'un abonnement) |
| `GET /api/accounts/{slug}/licence` | opérateur | clé de licence signée |
| `GET /api/entitlements/{slug}` | application, opérateur | droits + document signé |
| `POST /api/licences/verify` · `GET /api/licences/public-key` | application, opérateur | vérifier une licence, clé publique EdDSA |
| `GET /api/overview` | opérateur | MRR, ARR, comptes par statut, essais qui se terminent |
| `GET /api/audit-logs?account=&limit=` | opérateur | journal |

Corps d'un abonnement : `{"plan"?, "bricks"?: [], "options"?: [], "quantities"?: {"properties", "places", "screens", "mailboxes"}, "period"?: "monthly"|"yearly", "startsAt"?: "AAAA-MM-JJ", "endsAt"?: "AAAA-MM-JJ"}`.
