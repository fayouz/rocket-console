## Droits (entitlements)

`GET /api/entitlements/{compte}` avec un **jeton d'application** (`Bearer rco_…`, créé dans Administration → Applications) ou un administrateur :

```json
{
  "account": {"slug": "loussahousing", "name": "LoussaHousing", "status": "active"},
  "active": true, "plan": "rocket-location",
  "bricks": ["clean", "host", "mailer", "place", "stock"], "options": [],
  "quotas": {"properties": 2, "places": 2, "screens": 0, "mailboxes": 1},
  "period": "monthly", "issuedAt": "…", "expiresAt": "…",
  "token": "<JWS du même document>", "algorithm": "HS256"
}
```

Compte suspendu ou clôturé, essai échu ou pas d'abonnement : `bricks` vide et `active: false`. Échéance : fin d'essai, sinon +35 jours (mensuel) / +380 jours (annuel), bornée par la fin d'abonnement.

## Clé de licence

Le même document signé (JWS compact, claims `iss` = `rocket-console`, `sub` = compte, `iat`, `exp`) : bouton **Licence** de la fiche compte, `GET /api/accounts/{compte}/licence` ou `bin/console console:licence:issue <compte> [--claims]`.

Clé de signature : `rocket.console.signing_key` (coffre)
- `ed25519:<32 octets en base64>` → **EdDSA** : les instances auto-hébergées n'ont besoin que de la clé publique (`GET /api/licences/public-key`). Générer : `php -r 'echo "ed25519:".base64_encode(random_bytes(32)), PHP_EOL;'`.
- toute autre valeur de 32 caractères ou plus → **HS256** (secret partagé entre les instances de la suite).

Vérification côté brique (futur lecteur rocket-core) : découper sur `.`, décoder l'en-tête, vérifier `alg`, vérifier la signature de `<en-tête>.<contenu>` (`hash_hmac('sha256', …)` ou `sodium_crypto_sign_verify_detached`), puis `exp` ≥ maintenant. `POST /api/licences/verify {"token"}` fait la même chose côté console.
