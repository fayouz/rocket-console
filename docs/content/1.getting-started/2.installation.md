## Docker Compose

```bash
docker compose up -d --build
```

- Application : http://localhost:4200 (la configuration initiale crée le compte administrateur)
- API et documentation OpenAPI : http://localhost:9200/api/docs

## Développement sans Docker

```bash
# backend (PHP 8.4, PostgreSQL)
cd backend && composer install
php bin/console lexik:jwt:generate-keypair
php bin/console doctrine:migrations:migrate
php bin/console app:demo:seed            # avec DEMO_MODE=1 : catalogue par défaut, comptes « loussahousing » et « gite-des-oliviers »
php -S 127.0.0.1:9200 -t public

# frontend
cd frontend && npm install && npm run dev -- --port 4200
```

## Configuration

- `rocket.console.signing_key` (coffre) : clé de signature des droits et licences — `ed25519:<32 octets base64>` (EdDSA) ou secret de 32+ caractères (HS256). Vide : documents non signés, licences indisponibles (503). Voir [Droits et licences](/usage/licences).
- `php bin/console console:catalogue:seed` : crée le catalogue par défaut (sans rien écraser).
- Le worker (`php bin/console messenger:consume async scheduler_default`) lance les tâches récurrentes du socle (santé des services).
