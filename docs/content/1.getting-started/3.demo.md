```bash
docker compose -f compose.yaml -f compose.demo.yaml up -d --build
```

Ou sur GitHub : **Code → Codespaces → Create codespace** (rien à installer, voir `demo/README.md`).

| Compte | Mot de passe |
|---|---|
| `alice@example.org` (gestionnaire) | `demo-alice-password` |
| `admin@example.org` (administrateur) | `demo-admin-password` |

La démo contient le catalogue par défaut, le compte **loussahousing** (actif, Rocket Location pour 2 logements : 44 €/mois) et le compte **gite-des-oliviers** (essai de Rocket Host, 1 logement : minimum 29 €/mois, fin dans 12 jours). Connectez-vous en administrateur.

1. **Revenus** : MRR estimé, essais qui se terminent.
2. **Comptes → LoussaHousing** : ajouter une option, voir le devis, télécharger la **licence**.
3. **Catalogue** : modifier un prix ou une remise.
4. **Journal** : chaque modification.
